# Sinhala learner glosses

These glosses are what a Sinhala-speaking student memorizes for a Japanese word. They must name the Japanese word, not a word-for-word rendering of the English hint.

## Output

- Tab-separated, no header, no blank lines, no code fences.
- One output line per input line, same order, same id.
- The Sinhala field is one short gloss. No Japanese, romaji, or English left in it.
- If a gloss would contain a tab or a newline, use a space instead.

## How to choose the meaning

- Translate the Japanese headword (kanji + reading).
- Use the English only to pick the right sense when several Japanese words share a reading, or when one word has several everyday meanings.
- Do not translate English dictionary boilerplate. "to meet" is not "හමුවීමට". "that" is not "කියලා". "how" is not "කොහොමද කියලා".

## Form

- Verbs: spoken dictionary-style gloss ending in නවා. 会う → හමුවෙනවා. 食べる → කනවා. 行く → යනවා. する compounds stay natural: 勉強する → පාඩම් කරනවා.
- i-adjectives: predicative. 高い (expensive) → මිල වැඩියි. 高い (tall) → උසයි. 暑い → රස්නයි. 熱い → රත්වෙලා. 厚い → ඝනයි. 新しい → අලුත්.
- na-adjectives: 静か → නිශ්ශබ්දයි. 有名 → ප්‍රසිද්ධයි.
- Nouns: the everyday word. 水 → වතුර. 雨 → වැස්ස. 飴 → සීනි කැට. 私 → මම. 兄 → අයියා.
- Demonstratives: この → මේ. その → ඒ. あの → අර. これ → මේක. それ → ඒක. あれ → අරක.
- Two real everyday senses: separate with a comma. Do not paste every rare dictionary sense.
- A short Sinhala note in parentheses is allowed only to split a sense, for example රස්නයි (කාලගුණය).

## Kanji and radicals

- Kanji headwords: the learner meaning of that character. 日 → ඉර, දවස. 人 → මිනිසා. 国 → රට.
- Radicals: the meaning of that component. 日 / sun → ඉර. 一 / one → එක. Keep it to one or two words.
